INSTALL
=========

1) - Copy contents of "Modified" folder into root "Bruisers 2D Boxing" (Typically in Program Files (x86)\Steam\steamapps\common\Bruisers 2D Boxing), overwriting when prompted.

***IF YOU ARE USING THE UNDERCARD MOD, STEP 2 IS ALREADY COMPLETE, YOU ARE READY TO PLAY***

2) - Use UMT to export gml_Object_oInit_Other_4.gml (for backup/uninstall). Replace contents of gml_Object_oInit_Other_4.gml via UMT with the contents of the included script

3) - Launch Game



UNINSTALL
==========

1) - Copy contents of "Original" folder into root "Bruisers 2D Boxing" folder (Typically found @ Program Files (x86)\Steam\steamapps\common\Bruisers 2D Boxing), overwriting existing files when prompted.

*** IF YOU ARE/WERE USING THE UNDERCARD MOD, STEP 2 IS ALREADY COMPLETE ***

2) - Replace changed gml_Object_oInit_Other_4.gml with original/backup via UMT# z00t-music
