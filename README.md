INSTALL FOR USE WITH UNDERCARD MODPACK
=========
1) - Copy the "custom_music" folder into root "Bruisers 2D Boxing" (Typically in Program Files (x86)\Steam\steamapps\common\Bruisers 2D Boxing), overwriting/merging when prompted.
  
2) - Launch Game 



STANDALONE INSTALL (WITHOUT UNDERCARD MODPACK)
=========

1) - Copy ***contents*** of "custom_music" folder into the root "Bruisers 2D Boxing" folder (Typically in Program Files (x86)\Steam\steamapps\common\Bruisers 2D Boxing), overwriting when prompted.

2) - Use UMT (https://github.com/UnderminersTeam/UndertaleModTool) to export gml_Object_oInit_Other_4.gml (for backup/uninstall). Replace contents of gml_Object_oInit_Other_4.gml via UMT with the contents of the included script

3) - Launch Game



STANDALONE UNINSTALL
==========

1) - Copy contents of "Original" folder into root "Bruisers 2D Boxing" folder (Typically found @ Program Files (x86)\Steam\steamapps\common\Bruisers 2D Boxing), overwriting existing files when prompted.

2) - Replace changed gml_Object_oInit_Other_4.gml with original/backup via UMT (https://github.com/UnderminersTeam/UndertaleModTool)
